## 🚀 HOW TO USE

### For End Users
1. Download/extract project
2. Double-click **`AirTouch.bat`**
3. Select option 1 to start
4. Enjoy gesture control!

### For Configuration
1. From launcher menu, select option 2
2. Choose any of 9 tabs
3. Adjust settings
4. Changes apply immediately
5. Auto-saves on close

### For Profiles
1. From launcher menu, select option 6
2. Choose Gaming, Precision, Navigation, or Accessibility
3. Instant profile switching

### For Diagnostics
1. From launcher menu, select option 3
2. Automatic system health check
3. Recommendations provided

### For EXE Generation
1. `python build_exe.py`
2. Select option 1
3. Wait for build (few minutes)
4. .exe ready in `dist/` folder
