## 🎯 HOW TO USE

### For Regular Users

**Step 1: Install Dependencies**
```bash
Double-click: SETUP.bat
```
This automatically:
- Creates virtual environment
- Installs all dependencies
- Validates system
- Confirms everything works

**Step 2: Run Application**
```bash
Double-click: AirTouch_v35.bat
```
The application will:
1. Show splash screen
2. Let you select camera
3. Open configuration panel
4. Run test screen
5. Start gesture control

**Step 3: Enjoy!**
- Move hand to move cursor
- Push hand for click
- Press Q to exit

---

### For Developers

**Run with Python:**
```bash
# With virtual environment
.\airtouch_env\Scripts\activate
python main_new.py

# Or directly
python main_new.py
```

**Validate System:**
```bash
python validate_system.py
```

**Check Configuration:**
```bash
python quick_config.py
```

**Test Hand Visualization:**
```bash
python hand_visualizer.py
```

## 🎓 QUICK REFERENCE

### Getting Started
1. Run `SETUP.bat` (first time only)
2. Double-click `AirTouch_v35.bat`
3. Follow on-screen instructions
4. Enjoy gesture control!

### If Something Goes Wrong
1. Run `validate_system.py` for diagnostics
2. Check `START_HERE.md` for solutions
3. Read `README_v35_NEW.md` for details
4. Reinstall: `pip install -r requirements_v35_final.txt --force-reinstall`

### Configuration Tips
- **Too fast?** Lower "Speed" in config
- **Can't click?** Increase "Click Sensitivity"
- **Shaky?** Increase "Smoothing"
- **New profile?** Try Gaming, Precision, etc.
